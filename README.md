# 🌍 WanderWorld – Explore India Travel Guide

WanderWorld is a travel guide website designed to showcase some of the most popular tourist destinations in India. It provides information about destinations, travel packages, and a contact form for enquiries through a simple and user-friendly interface.

## ✨ Features

* **Navigation Bar:** Easily navigate between different sections of the website.
* **Hero Section:** Attractive landing section with a background image and call-to-action button.
* **Popular Destinations:** Explore Agra, Goa, Jaipur, and Manali.
* **Travel Packages:** View different travel packages with sample prices.
* **Contact Form:** Enter your name, email, preferred destination, and message.
* **CSS Hover Effects:** Interactive buttons and destination cards.
* **Smooth Scrolling:** Smooth navigation between sections.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Transitions and Hover Effects

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Keep the HTML, CSS, and image files in the correct locations.
3. Open `index.html` in your web browser.
4. Explore the different sections of the website.

## 🎯 Project Objective

The objective of this project is to practice HTML and CSS by creating a travel guide website with structured content, flexible layouts, images, navigation links, and interactive styling.
